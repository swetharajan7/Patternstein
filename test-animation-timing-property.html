Property Test: Tip Rotation Interval Consistency

Property 1: Tip rotation interval consistency
Property: For any tip in the collection, when displayed, the next tip should appear after exactly 5 seconds (±100ms tolerance for timing precision)
Validates: Requirements 1.2 - WHEN 5 seconds elapse THEN the system SHALL fade out the current tip and fade in a new tip
Test Strategy: Measure the actual time between multiple tip rotations and verify they all fall within the acceptable range
